## **✨ Features**

| Feature | Status | Details |
|---------|--------|---------|
| 🔐 **Authentication** | ✅ | Signup, login, password reset via Supabase |
| 💬 **Messaging** | ✅ | 1-on-1 & group chat with real-time updates |
| 🎙️ **Voice Messages** | ✅ | Record and send voice messages |
| 📸 **Media Sharing** | ✅ | Send images, videos, and files |
| ☎️ **Voice Calls** | ✅ | 1-on-1 and group calls via Zego Cloud |
| 📹 **Video Calls** | ✅ | Crystal clear video calling |
| 👥 **Friends** | ✅ | Add friends, manage requests |
| 📱 **Profile** | ✅ | Customizable user profiles |
| 🔔 **Notifications** | ✅ | Push notifications ready |
| ⚙️ **Settings** | ✅ | Comprehensive settings panel |
